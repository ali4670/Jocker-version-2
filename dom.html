Fair play

One code.
One player.

  1. You order

    Your name, phone and address are saved with the order, along with the pieces it carries.

    1

  2. You get a code

    A QR code is created for that order alone. It holds your details, the items and the exact piece count.

    2

  3. The rep scans it

    The rep checks the code on delivery and photographs the puzzle piece as it is handed over.

    3

  4. The code burns

    After one scan it is spent. A shared copy, an edited piece count or a second scan is refused.
